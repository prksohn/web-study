## Advanced CSS (4) - CSS Function

### CSS 함수란?

값을 계산하거나 결정해주는 기능

```css
property: 함수();
```

### 1. `calc()` - 값 계산

```css
width: calc(100% - 40px);
```

- 100%에서 40px을 뺀 값을 사용하라는 의미
- 예를 들어, 부모가 500px 이라면
- 500px - 40px = 460px 따라서 width : 460px로 적용
- 부모의 크기를 알 수 없기 때문에 미리 지정하지 않고, 부모의 크기에 따라 계산하여 사용
- 단위끼리 계산 가능 `calc(100% - 20px);`, `calc(100vh - 80px);`, `calc(100vh - 80px);`
- 연산자도 가능 : 곱셈, 나눗셈은 `calc(100px * 2);` 처럼 사용 가능
- 고정된 크기 + 유동적인 크기 조합할 때 유용

### 2. `min()` - 여러 값 중 가장 작은 값

```css
width: min(500px, 100%);
```

- 500px과 100% 중 더 작은 값 사용
- 부모가 800px 이라면, `min(500px, 800px)` 중 500px 사용 = 500px보다 커지지 않게
- 최대한 500px까지만 사용하고 부모보다 커지지 말라는 뜻 = 최대 크기 제한하면서 화면 크기에 맞춰 줄어든다.

### 3. `max()` - 여러 값 중 가장 큰 값

```css
width: max(300px, 50%);
```

- 300px과 50% 중 더 큰 값 사용
- 부모가 400px 이면, `max(300px, 200px)` 중 300px 사용 = 최소 300px 정도 확보

### 4. `clamp()` - (최소 ~ 선호 ~ 최대) 범위 제한

반응형 글자 크기 설정 <br>
글자 크기 뿐만 아니라, 값이 어느 범위 안에서 유동적으로 변해야 할 때 사용

```css
clamp(최소값, 선호값, 최대값);

font-size: clamp(16px, 2vw, 32px);
```

- 브라우저가 계산한 2vw가 16px보다 작으면 -> 16px
- 16px - 32px 사이면 2vh
- 32px보다 크면 -> 32px

### 5. `calc()` 과 `clamp()` 활용

```css
clamp(300px, calc(100% - 40px), 1200px)
```

- 계산된 값이 300px보다 작으면 300px 사용
- 300-1200px 사이면 계산된 값을 사용하고
- 1200px보다 크면 1200px 사용
- 선호값은 부모의 크기에 따라 변동
