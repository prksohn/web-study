## 콘텐츠

웹 페이지에 링크, 이미지, 목록 등의 콘텐츠를 표현할 때 사용

### 1. `<a>` 링크

다른 페이지나 위치로 이동하는 링크 만들 때 사용

#### 기본 형태

```html
<a href="이동할 주소">링크 내용</a>
```

- `a` : 링크 생성
- `href` : 어디로 이동할지 지정
- `링크 내용` : 사용자가 보는 링크 내용

#### 다른 페이지로 이동

내 웹사이트 안의 다른 페이지로 이동

```html
<a href="/파일명">링크 내용</a>
```

#### 외부 사이트로 이동

```html
<a href="https://...">링크 내용</a>
```

#### 주의점

링크와 버튼 구분 필요

- 링크 : 다른 페이지로 이동
- 버튼 : 어떤 동작을 실행

### 2. `<img>` 이미지

웹 페이지에 이미지를 표시할 때 사용

#### 기본 형태

```html
<img src="폴더명/파일명.jpg" alt="대체 텍스트" />
```

- `src` : 어떤 이미지를 보여줄지
- `alt` : 그 이미지가 무엇인지 설명
- 파일 경로는 `index.html`을 기준

### 3. `<li>` 목록의 항목

list item, 목록의 각각의 항목

```html
<li>내용</li>
```

### 4. `<ul>` 순서가 없는 목록

unordered list, 순서가 중요하지 않은 목록
반드시 `li`와 함께 사용

#### 기본 형태

```html
<ul>
  <li>내용</li>
  <li>내용</li>
  <li>내용</li>
</ul>
```

### 5. `<ol>` 순서가 있는 목록

ordered list, 순서가 중요한 목록

```html
<ol>
  <li>내용</li>
  <li>내용</li>
  <li>내용</li>
</ol>
```
