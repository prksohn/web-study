## HTML Fundamentals

### HTML이란?

웹 페이지의 구조를 만드는 마크업 언어

### 기본 구조

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <title>웹 페이지 제목</title>
  </head>

  <body>
    <h1>제목</h1>
    <p>내용</p>
  </body>
</html>
```

### 기본 태그

- `<!DOCTYPE html>` : HTML 문서 형식을 브라우저에 알려주는 선언, 문서 상단에 위치

- `<html>` : HTML 문서 전체를 감싸는 가장 바깥쪽 요소
- `<lang="ko">` : 문서에 작성된 언어

- `<head>` : 웹 페이지에 대한 정보
- `<title>` : 웹 페이지 제목

- `<body>` : 실제 화면에 표시되는 내용
- `<h1>제목</h1>` : 가장 큰 글씨
- `<h2>제목</h2>`
- `<h3>제목</h3>`
- `<h4>제목</h4>`
- `<h5>제목</h5>`
- `<h6>제목</h6>` : 가장 작은 글씨
- `<p>` : 문단, paragraph의 약자
