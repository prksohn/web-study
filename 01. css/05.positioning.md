## 포지셔닝 ositioning

### Positioning이란?

요소를 원하는 위치에 배치하는 방법

```css
선택자 {
  position: static;
  position: relative;
  position: absolute;
  position: fixed;
  position: sticky;
}
```

### 1. `position: static` - 기본값

HTML 요소는 기본적으로 `static`, 일반적인 문서 흐름에 따라 순서대로 배치

```css
선택자 {
  position: static;
}
```

- `static` 에서는 `top`, `right`, `bottom`, `left` 와 같은 위치 이동 속성 적용 불가

### 2. `position: relative` - 원래 위치를 기준으로 이동

두 가지 용도가 있는데, 원래 자기 위치를 기준으로 이동하거나 `absolute` 의 기준점이 된다.

```css
선택자 {
  position: relative;
}
```

- 원래 자기 위치를 기준으로 이동하지만, 원래 차지하던 공간은 그대로 유지
- absolute의 기준점
- 특히, `relative` + `absolute`

### 3. `position: absolute` - 일반적인 문서 흐름에서 빠져서 위치 지정

일반적인 레이아웃 흐름에서 빠져서 다른 선택자들의 배치에는 영향을 주지 않는다.

```css
선택자 {
  position: absolute;
}
```

- 배지, 아이콘, 버튼, 이미지 위의 텍스트, 모달 내부 요소, 장식 요소 등에 주로 사용
- `relative` : 부모
- `absolute` : 자식
- 즉 자식인 `absolute` 는 부모인 `relative` 를 기준으로 배치 된다.

````

### 4. `top`, `right`, `bottom`, `left` - 원하는 방향으로 위치 이동

부모 요소를 기준으로 자식 요소를 원하는 위치로 이동

```css
부모 요소 {
  position: relative;
}


자식 요소 {
  position: absolute;
  top: 10px;
  right: 10px;
  bottom: 10px;
  left: 10px;
}
````

### 5. `position: fixed` - viewport 화면을 기준으로 고정

스크롤 해도 같은 위치에 고정

```css
선택자 {
  position: fixed;
}
```

- 문의 버튼, 맨 위로 가기 버튼, floating action button, 고정된 헤더, 특정 UI 컨트롤 등에 주로 사용
- 처음부터 붙어 있음

### 6. `position: sticky` - 스크롤에 따라 특정 위치에 붙음

평소에는 일반적인 흐름에 있다가, 스크롤해서 특정 위치에 도달하면 붙어 있는 것처럼 동작

```css
선택자 {
  position: sticky;
}
```

- 섹션 제목, 테이블 헤더, 페이지의 상단 메뉴, 필터 영역 등에 사용
- 스크롤 하다가 붙음

### 7. `z-index` - 겹친 요소들의 앞뒤 순서 조절

요소가 겹칠 때, 어느 요소가 위에 보일지 정하는 속성

```css
선택자 {
  position: absolute;
  z-index: 1;
}

선택자 {
  position: absolute;
  z-index: 2;
}
```

- 숫자가 높을수록 상단에 위치
- 단, 숫자가 높다고 모든 상황에서 위로 올라오는 것도 아니다 (stacking context)
